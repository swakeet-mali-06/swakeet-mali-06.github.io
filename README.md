# Swakeet Mali — Portfolio

A creative personal portfolio website built with HTML, CSS and JavaScript and designed for deployment with GitHub Pages.

## Files
- `index.html` — main portfolio page
- `css/style.css` — visual design and responsive layout
- `js/main.js` — small scroll/reveal interactions
- `assets/` — place profile images, certificates or resume here if needed

## Deploy on GitHub Pages
1. Put these files in the root of your repository.
2. Commit and push:
   `git add .`
   `git commit -m "Create creative personal portfolio"`
   `git push`
3. Open GitHub → repository → Settings → Pages.
4. Select **Deploy from a branch**, choose **main** and **/ (root)**.
5. Save and open the generated GitHub Pages URL.

The reference assignment describes the same overall workflow: structure the site into HTML/CSS/JS/assets, use staged Git commits, push to GitHub, enable Pages from the main branch, and verify the live site.
